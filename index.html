Verified Pain Points

Hermes Agent — Top Issues

  • Install failures: PATH, Python 3.12, Windows unsupported (WSL2 only)
  • Gateway disconnects: WSL2 drops, port conflicts, Telegram/Discord unresponsive
  • Memory leaks: Residual gateway memory under heavy cron sessions
  • Local model failures: Ollama GPU detection, GGUF errors, malformed JSON
  • Tool-call loops: Agent hangs, sub-agent context loss, MCP load failures
  • Patch parser (critical): Files >2000 lines silently truncated on UPDATE (#6831)
  • Docker errors: v2026.4.23 image chown failures
  • Security: 9 CVEs disclosed March 2026 (memory/replay attack surface)
  • Bug backlog: 20 open P0, 36 open P1, only 33.4% bug close rate

OpenClaw — Top Issues

  • Gateway crash loops: Bonjour plugin, Mac M4 launchd respawn cycles
  • Plugin regressions: Discord/Telegram crashes after version bumps
  • Install failures: Node v22 required, npm errors, node-gyp/Sharp
  • CPU/memory spikes: memory index --force pegs cores; group-chat leak risk
  • Security (severe): CVE-2026-25253 token exfiltration, CVE-2026-33579 privilege escalation, 135k+ instances to RCE
  • Update regressions: Minor bumps break integrations repeatedly
  • Bot triage: clawsweeper[bot] closes many issues in hours — may mask real problems
  • Stale issues: 49% of open issues are >90 days old

Methodology & Caveats

  • Data collected on 2026-05-04 via GitHub REST API v3 and Search API.
  • open_issues_count includes PRs — we used is:issue search for actual issue counts.
  • Close times sampled from 50 recently closed items, filtered to exclude PRs.
  • OpenClaw uses clawsweeper[bot] for auto-closure; its 0.1-day median is not human resolution time.
  • Hermes labels many support tickets as type/bug; actual verified defect rate is likely lower than 68%.
  • Stars are a community-size proxy, not an active-user count.
  • Both projects had commits on 2026-05-04 and are actively maintained.
