Where Each Wins

Hermes Agent

  • One-line shell installer (batteries included)
  • Built-in self-improving learning loop + skill curation
  • Python-native stack; easy to hack on
  • No telemetry; fully local by default
  • Higher PR merge rate (85%)

OpenClaw

  • Massive plugin/skills marketplace (700+ skills)
  • Multi-agent isolation on one Gateway
  • Polished web UI + 30+ messaging platforms
  • Much higher issue close rate (90%)
  • Lower normalized defect density per star

Known Pain Points

Hermes Pain Points

  • Higher open-issue volume relative to user base
  • Type/bug label rate is high (includes setup/env issues)
  • No built-in web UI (CLI/TUI first)

OpenClaw Pain Points

  • Setup complexity: Node, daemon, Docker Compose options
  • Token-usage spikes reported at scale
  • ~2 GB RAM footprint in Docker
  • CVE-2026-25593 patched (historical advisory)

Methodology

Data was collected on 2026-05-04 from the GitHub REST API and Search API. We normalized open issues, forks, and bug density against stars as a proxy for community size. Labels were sampled from the first 100 issues returned by the API (recent issues).

  • Stars ≈ community size proxy
  • Labels are not uniform across repos; read with context
  • PR merge rate is a sample; lifetime rate may differ
  • Both projects are actively maintained (last commit today)
